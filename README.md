# 림버스 TRPG 캠페인 보조실

ChatGPT가 GM, 사용자가 플레이어가 되어 진행하는 1인용 TRPG를 위한 캠페인 보조 웹앱입니다.

## 현재 기능
- 캠페인 정보, 현재 상황, 목표 및 GM 인계 메모
- 캐릭터 기본 정보와 7죄악 전문 속성 선택 기록
- 전투 방식, 무기, 스킬·장비·패시브 메모
- 단계형 체력 칸 수와 피해 기록
- 진행·판정 기록 및 NPC 관계 기록
- 룰북 기본 판정 요약
- 브라우저 자동 저장 및 JSON 백업·복원

## 규칙 관련 원칙
캐릭터 메이킹과 판정 참고는 업로드된 **LIMBUS TRPG SYSTEM 공개 테스트판 v0.7**을 기준으로 정리했습니다. 캐릭터의 체력 칸 수 등 룰북이 고정하지 않은 값은 사용자와 GM이 합의해 입력합니다. 앱은 임의 주사위를 굴리거나 판정·피해를 자동 확정하지 않습니다.

## 배포
GitHub Actions가 `main` 브랜치에 커밋이 올라올 때 GitHub Pages에 자동 배포합니다.

저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택하세요.

## 데이터 저장
캠페인 데이터는 브라우저의 localStorage에 저장됩니다. 사이트 코드가 GitHub에 배포되어도 개인 캠페인 데이터는 GitHub로 전송되지 않습니다. 다른 브라우저나 기기에서 이어 하려면 JSON 백업을 내려받아 복원하세요.
