선수 평가

합의된 능력치 가중치와 등급 구간을 적용한 참고 지표입니다. 게임 공식 종합점수가 아닙니다.

트레이드 제안 검토

선수 ID를 기준으로 양 구단 제공·영입 선수를 선택해 원본 자료 기반 ChatGPT 검토문을 만듭니다. 게임 원본 수치는 변경하지 않습니다.

재계약 검토

선수 ID를 입력하면 현재 구단 소속 선수의 원본 계약·능력치·부상 필드를 묶어 검토합니다. 연봉 단위나 계약 규칙을 임의로 추정하지 않습니다.

재정·연봉 관리

원본 sal 합계·평균·포지션별 지출·yrs/faC 분포를 표시합니다. cap/cash 의미와 게임 공식 한도 규칙은 추측하지 않습니다.

정규시즌 팀 리뷰

원본 hist에서 해당 연도 1군 기록만 추출합니다. 팀 순위·개별 선수 성적은 확인 가능한 원본 데이터만 사용합니다. 분석은 ChatGPT 웹 대화용 프롬프트로 생성합니다.

단장 평가 · ChatGPT 웹대화

API 키·API 호출 없이 질문과 세이브 분석 자료를 복사해 ChatGPT 웹에서 이어갑니다.

합의된 규칙

원본 패키지의 data/agreed_rules.json에 정의된 사용자 합의 기준입니다. 게임 공식 규칙과 구분합니다.
